設定

同期・カテゴリ・場所・リマインドの設定です。

1. 同期方法

接続用リンクをお持ちの場合

同期済みの端末で表示した「接続用リンク」を貼り付けて「接続」を押すと、下の2と3を入力しなくても接続できます。

2. Firebase 接続情報

Firebaseコンソールの「プロジェクトの設定」→「マイアプリ」に表示される const firebaseConfig = { ... }; の部分を、コピーしたまま貼り付けてください（書き換えは不要です）。日用品ストック管理と同じFirebaseプロジェクトを使うこともできます。

3. 共有コード

同じコードを入力した端末同士でデータが共有されます。長めのランダムな文字列を推奨します。

他の端末を追加する

新しいスマホやPCを同期に加えるための、接続用リンクとQRコードを表示します。

このリンクとQRコードには共有コードが含まれています。同期したい人にだけ渡し、SNSなどには載せないでください。

iPhoneで「ホーム画面に追加」したアプリを使う場合：QRコードをカメラで読むとSafariで開いてしまうため、リンクをコピーして、ホーム画面のアプリの「設定」→「接続用リンクをお持ちの場合」に貼り付けてください。

カテゴリ管理

TODOの分類です。自由に追加・削除できます。クラウド同期中は、すべての端末で共通になります。

場所の管理

TODOをやる場所です（例：自宅、会社、車）。「今やること」「これから」で場所ごとに絞り込めます。クラウド同期中は、すべての端末で共通になります。

リマインド（カレンダーで毎日お知らせ）

毎日決まった時刻に「今やること」を確認する予定を、カレンダーに登録します。予定の通知や予定の中のリンクから、アプリの「今やること」を直接開けます。

Googleカレンダーの場合、予定を保存する前に通知を「予定の時刻」（0分前）にすると、その時刻ちょうどに通知が届きます。「iPhone・その他」はカレンダー用ファイル（.ics）を作ります。開くとカレンダーに追加でき、時刻ちょうどの通知も設定済みです。
