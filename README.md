# MEGURU（めぐる）

「くりかえすTODO」と「1回きりのTODO」を、**サイクル（間隔）**と**場所**で管理するWebアプリです。
「日用品ストック管理」と同じ考え方（「やった」ボタン1つで次回を自動計算・履歴から平均間隔を出す・Firebaseで端末間同期）で作っています。

---

## できること

- **くりかえしTODO**：「○日ごと・○週間ごと・○か月ごと・○年ごと」で登録（毎日／毎週／2週間／毎月／3か月／半年／毎年のワンタップ選択あり）。「✓ やった」を押すと、その日から次回の予定日を自動計算
- **1回きりTODO**：期限つき、または期限なしで登録。「やった」で完了になり、「すべて」タブの「完了した1回きりのTODO」に移ります（戻す・削除が可能）
- **サムネイル**：40種類以上のピクトグラム（家事・暮らし・仕事/IT・お金/手続き・移動）と9色から選ぶか、写真をアップロード（スマホで撮影・写真ライブラリから選択）。新しく追加するときは、名前から自動でアイコンを選びます（例：「エアコンのフィルター掃除」→エアコン）
- **サイクルのリング**：サムネイルのまわりのリングで、前回から次回までの進み具合がひと目でわかります（まもなく＝オレンジ、期限切れ＝赤）
- **場所**（自宅・会社・外出先・車・ネットなど）を登録し、「今やること」「これから」で場所ごとに絞り込み。場所の一覧は設定タブで自由に追加・削除
- **延期**：明日／3日後／1週間後／次の土曜／日付指定。くりかえしTODOは今回だけ日付が変わり、「やった」を押すと元の間隔に戻ります
- **元に戻す**：「やった」を押し間違えても、表示されるお知らせの「元に戻す」で取り消し
- 編集画面に過去4回までの「やった日」と**実際の平均間隔**を表示し、ボタン1つで間隔に反映
- タブ構成：「今やること」（期限切れ・今日・まもなく）／「これから」（1週間以内・1か月以内・それ以降）／「すべて」（検索・カテゴリ・場所・種類で絞り込み）／「設定」
- カレンダーで毎朝リマインド（Googleカレンダー／iPhoneなど）。予定のリンクから「今やること」を直接開けます
- スマホのホーム画面・PCに「アプリ」として追加可能（PWA）
- Firebaseを使った端末間の自動同期（任意）。接続用リンク・QRコードで新しい端末をかんたんに追加
- データのエクスポート／インポート（JSONファイル）

> **リマインドについて**：OSの通知（プッシュ通知）は行いません。アプリを開いたときに「今やること」に表示される仕組みです。

## 公開する（GitHub Pages）

日用品ストック管理と同じ手順です。

1. GitHubで新しいリポジトリ（例：`meguru`）を作り、Public を選んで作成。
2. 「Add file」→「Upload files」で、このフォルダの中身（`index.html`・`app.js`・`icons.js`・`qrcode.js`・`styles.css`・`manifest.json`・`sw.js`・`icons`フォルダ）をまとめてドラッグ＆ドロップし、「Commit changes」。
3. 「Settings」→「Pages」→ Source を **Deploy from a branch**、Branch を **main / (root)** にして「Save」。
4. 1〜2分後に表示される `https://（ユーザー名）.github.io/meguru/` をスマホ・PCで開きます。
5. スマホ：共有メニューから「ホーム画面に追加」。PC：アドレスバーのインストールアイコンから追加。

> 日用品ストック管理と同じGitHubアカウントで公開しても、データの保存場所（キー名）は別々なので混ざりません。

## クラウド同期を設定する

### 日用品ストック管理と同じFirebaseプロジェクトを使う場合（おすすめ・かんたん）

すでにFirebaseを設定済みなら、**ルールを追加するだけ**で使えます。

1. Firebaseコンソール → Firestore →「**ルール**（Rules）」タブを開きます。
2. 中身をすべて消し、同梱の `firestore.rules` の中身を貼り付けて「**公開**（Publish）」。
   （このファイルには、日用品ストック管理用のルールも入っているので、そちらの同期も今までどおり動きます）
3. MEGURUの「設定」→「クラウド同期する」に、日用品ストック管理と同じ `firebaseConfig` を貼り付けます。
4. 「コード生成」でMEGURU用の共有コードを作り（日用品ストック管理とは別のコードでOK）、「保存して接続」。
5. 右上が「同期中：〇〇」になれば成功です。2台目以降は「他の端末を追加する」のリンク・QRコードが便利です。

### 新しくFirebaseプロジェクトを作る場合

日用品ストック管理のREADMEの手順A〜Fと同じです（プロジェクト作成 → Firestore を `(default)`・東京・本番環境モードで作成 → ルール設定 → 匿名ログインを有効化 → ウェブアプリを登録して `firebaseConfig` をコピー → アプリに貼り付け）。ルールは同梱の `firestore.rules` を使ってください。

MEGURU用のルール部分：

```
match /meguru/{code}/tasks/{taskId} {
  allow read, write: if request.auth != null;
}
match /meguru/{code}/meta/{docId} {
  allow read, write: if request.auth != null;
}
```

### 新しい端末を追加する（接続用リンク・QRコード）

1. 同期中の端末で「設定」→「他の端末を追加する」→「接続用リンクとQRコードを表示」。
2. 新しい端末でQRコードを読み取るか、リンクを「設定」→「クラウド同期する」→「接続用リンクをお持ちの場合」に貼り付けて「接続」。

> **iPhoneで「ホーム画面に追加」したアプリを使う場合**：Safariとホーム画面のアプリは保存場所が別々です。リンクを貼り付ける方法でホーム画面のアプリに入力してください。

> 接続用リンクとQRコードには共有コードが含まれています。同期したい人にだけ渡してください。

## 安全対策

- 写真は「このアプリが作った画像データ」だけを表示します（外部URLの画像は読み込まないため、ページの設定 `img-src` からも外部を外しています）
- インポートしたファイル・同期で届いたデータ・端末に保存されたデータは、使う前に決まった形に整え、おかしな値は捨てます
- Content Security Policy（CSP）を設定し、万一スクリプトが紛れ込んでも動かないようにしています
- 共有コードの「コード生成」は推測されにくい安全な乱数（約80ビット）で作ります
- 接続用リンクから接続するときは、この端末のデータを自動でコピーする提案はしません。今と違う同期先に切り替わる場合は確認画面で警告します

## データのバックアップ

設定タブの「データをエクスポート」でJSONファイルとして保存、「インポート」で復元できます。

## 困ったときは

- 更新したのに画面が変わらない → ページを再読み込み。それでもだめなら、ブラウザの「サイトデータの削除」を一度行ってください
- 「保存して接続」で赤いメッセージが出る → 表示された原因（匿名ログインが無効、ルール未設定など）を確認してください
- 「カテゴリ・場所が同期されていません」と出る → Firestoreのルールに `meguru/{code}/meta` の部分が入っているか確認してください
